# Fractal Builder

Привет! Это мой учебный проект по теме «Фракталы».

Я написал приложение на C, которое строит множества Мандельброта и Жюлиа.
В программе можно менять константу Жюлиа, смотреть координаты, выделять область
мышью и приближать фрактал колесом. Графический интерфейс сделан на GTK 4.

## Возможности программы

- построение множеств Мандельброта и Жюлиа;
- изменение действительной и мнимой частей константы Жюлиа;
- автоматическая перерисовка после изменения параметров;
- отображение комплексных координат под курсором;
- увеличение выделенной области;
- масштабирование колесом мыши;
- возврат к начальному виду;
- многоцветная отрисовка фрактала.

## Краткое объяснение

Каждый пиксель изображения переводится в точку комплексной плоскости. Для неё
много раз вычисляется формула `z(n + 1) = z(n)² + c`. Если значение выходит за
радиус 2, программа запоминает количество выполненных итераций и выбирает по
нему цвет пикселя.

Для множества Мандельброта начальное значение `z` равно нулю, а `c` задаётся
координатой пикселя. Для множества Жюлиа начальное `z` задаётся пикселем, а
константу `c` пользователь выбирает ползунками.

## Запуск

Для сборки нужны компилятор C, `make`, `pkg-config` и GTK 4.

В Debian/Ubuntu зависимости можно установить так:

```bash
sudo apt install build-essential pkg-config libgtk-4-dev
```

Сборка и запуск:

```bash
git clone git@github.com:K35177/fractal-builder.git
cd fractal-builder
make run
```

Также можно сначала собрать программу, а затем запустить её отдельно:

```bash
make
./fractal_builder
```

## Управление

- выберите Мандельброта или Жюлиа в левой панели;
- для Жюлиа изменяйте действительную и мнимую части константы ползунками;
- выделите область левой кнопкой мыши, чтобы приблизить её;
- используйте колесо мыши для масштабирования;
- нажмите `[ сбросить ]`, чтобы вернуться к начальному виду.

Основной код находится в файле [`main.c`](main.c).
